# 🚨 Sistema de Alerta de Desastres Naturales - Perú

¡Bienvenido! Este es un sistema inteligente de monitoreo y alerta temprana de desastres naturales en el Perú, diseñado para ofrecer información precisa, oficial y en tiempo real con la finalidad de salvaguardar vidas.

## 🌟 Características Principales

* **Ubicación Inteligente:** La aplicación inicia por defecto mostrando la actividad de **Lima (Lima, Lima)**, pero se sincroniza y actualiza instantáneamente en tiempo real si el usuario activa su GPS o selecciona manualmente cualquier otra región del Perú.
* **Filtro Estricto de 24 Horas:** Para evitar la difusión de noticias falsas o información obsoleta, el sistema filtra matemáticamente los reportes y muestra **únicamente** los acontecimientos registrados en las últimas 24 horas.
* **Alertas de Emergencia:** Integra un sistema optimizado para disparar alertas sonoras persistentes cuando un desastre inminente afecte la ubicación del usuario.

## 🏥 Monitoreo de Fuentes Oficiales

La aplicación se conecta de manera directa para extraer información y generar enlaces específicos (Deep Links) hacia los boletines de las 7 instituciones oficiales de emergencia en el Perú:

1. **IGP** (Instituto Geofísico del Perú) - Reportes sísmicos individuales en tiempo real.
2. **SENAMHI** (Servicio Nacional de Meteorología e Hidrología) - Avisos meteorológicos e hidrológicos.
3. **INDECI** (Instituto Nacional de Defensa Civil) - Reportes de emergencia nacional.
4. **COEN** (Centro de Operaciones de Emergencia Nacional) - Boletines informativos diarios.
5. **CENEPRED** (Centro Nacional de Estimación, Prevención y Reducción del Riesgo de Desastres) - Escenarios de riesgo.
6. **SIGRID** (Sistema de Información para la Gestión del Riesgo de Desastres) - Monitoreo de peligros.
7. **DHN** (Dirección de Hidrografía y Navegación) - Alertas de tsunami y avisos de oleaje anómalo.
